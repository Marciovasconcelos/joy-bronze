# Joy Bronze ☀️

## Cliente
Não precisa de conta, senha ou e-mail.

A cliente informa apenas:
- Nome
- Telefone
- Serviço
- Data
- Horário

## Administração
Acesse `admin-login.html`.

O administrador continua usando:
- E-mail
- Senha

Para ter acesso administrativo, o documento do usuário em `usuarios/{UID}` deve conter:

`tipo: "admin"`
